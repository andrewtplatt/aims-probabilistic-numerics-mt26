# Probabilistic Numerics — MT26

Code and experiments for the **AIMS Probabilistic Numerics** course, Michaelmas Term 2026.

The repository contains a Jupyter notebook (`main.ipynb`), Gaussian process lab exercises (`gp_lab.pdf`), and supporting data (`sotonmet.txt`).

## Getting started

Requires Python 3.12+ and [`uv`](https://docs.astral.sh/uv/).

```bash
uv sync
uv run jupyter lab
```

Open `main.ipynb` to explore the exercises and experiments.
